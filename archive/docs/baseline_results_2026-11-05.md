# 기준 모델 첫 결과와 결론 (11/5)

> 팀원용 요약. 앞으로 만들 모델(M1~M3)과 비교할 "출발점" 숫자다. 시드가 1~3개뿐이라 **예비 결과**로 읽어야 한다.

## 결론 먼저

1. **"0.01초 뒤 예측"만 보면 신경망이 20배 낫지만, "1초 뒤 예측"에서는 물리 모델이 같거나 더 낫다.** 특히 타이어가 한계에 있는 구간에서 그렇다(D1). 원논문처럼 1스텝 오차만 보면 잘못된 결론을 낼 수 있다. → 우리 주 지표는 **롤아웃(몇 초 앞 예측) 오차**로 한다.
2. **신경망은 같은 구조, 같은 데이터인데도 시드만 바꾸면 1초 예측 오차가 20배까지 차이 난다(D2).** 한 번 돌린 결과로 결론을 내면 안 된다. → 모든 비교는 **시드 여러 개(5개)**로 한다. 이 불안정성을 물리 구조가 줄여 주는지가 우리 핵심 질문(RQ1)이다.
3. **처음 보는 노면(μ)에서는 신경망 오차가 약 3.5배 커진다(D2 실데이터).** "물리 구조가 있으면 새 노면에 덜 무너질 것"이라는 RQ3를 실데이터로 검증할 수 있다는 첫 근거다.
4. **합성 데이터(D3)에서는 지금 물리 모델이 크게 진다.** 다만 물리 모델이 노면 μ를 모른 채 하나의 μ로 모든 노면을 맞추게 되어 있어서 공정한 비교가 아니다. → **팀 결정 필요** (아래 참고)

## 무엇을 했나

### 비교한 모델 (둘 다 원논문 구조)

| 이름 | 무엇 | 학습하는 것 |
| --- | --- | --- |
| **M0 신경망** | 과거 0.04초(4시점)의 속도·조향·구동 입력을 보고 0.01초 뒤를 예측하는 128×2 신경망 | 전부 |
| **B1 물리 모델** | 타이어 공식(Fiala)을 쓴 자전거 모델 | 앞뒤 타이어 강성 2개와 마찰계수 μ 하나만 |

원논문과 달라진 점은 데이터를 주행 단위로 나눈 것, 입력 정규화, 학습 설정(조기 종료 등)이다. 모델 구조는 같다.

### 평가 방법

| 지표 | 뜻 |
| --- | --- |
| **1스텝 오차** | 0.01초 뒤를 얼마나 잘 맞추나. 원논문이 쓴 방식 |
| **롤아웃 오차** | 처음 0.04초만 실제 값을 주고, 그 뒤로는 **모델이 자기 예측을 다시 입력으로 써서** 0.1/0.5/1.0초 앞까지 예측. 실제 제어(MPC)에서 모델을 쓰는 방식과 같다 |
| **구간별 오차** | 타이어가 평소 / 한계 진입 / 한계(포화) 중 어디에 있을 때의 오차인지 나눠서 봄 |

오차는 모두 데이터의 변동 폭으로 나눈 값이다. **0이면 완벽, 1이면 "평균값만 찍는" 수준**이다.

## 데이터별 결과

### D1 승용차 (시험: 주행 2개, 2.6분)

| | 1스텝 | 0.5초 앞 | 1.0초 앞 | 1.0초 앞 (포화 구간) |
| --- | --- | --- | --- | --- |
| B1 물리 모델 | 1.17 | 0.27 | **0.33** | **0.68** |
| M0 신경망 (시드 3개) | **0.05** | 0.26~0.29 | 0.37~0.44 | 0.92~1.24 |

- 0.01초 뒤는 신경망이 압도적이다. 그런데 자기 예측이 쌓이면 신경망 오차가 더 빨리 커진다.
- 포화 구간에서 1초 앞을 예측하면 물리 모델 오차가 신경망의 55~75% 수준이다.
- 주의: 시험 주행이 2개, 포화 구간 롤아웃이 64개뿐이다. D1은 전체가 11개 주행이라 분할에 따라 결과가 쉽게 흔들린다.

### D2 RC카 (시험: 주행 15개, 5.8분, 대부분 포화 구간)

| | 1스텝 | 0.5초 앞 | 1.0초 앞 |
| --- | --- | --- | --- |
| M0 시드 0 | 0.21 | 0.52 | 3.56 |
| M0 시드 1 | 0.22 | 0.46 | 1.06 |
| M0 시드 2 | 0.21 | 0.57 | **20.1** |

- 1스텝과 0.5초까지는 세 시드가 비슷하다. 1초에서 갑자기 갈라진다.
- D2에는 물리 모델 비교가 없다. D2의 구동 입력은 힘이 아니라 모터 전류라서, 물리 모델에 넣으려면 모터 모델이 따로 필요하다.

### D2 처음 보는 노면 (타이어 A·B로 학습 → 타이어 C·D로 시험)

| | 1스텝 (전체) | 1스텝 (포화) | 1.0초 앞 |
| --- | --- | --- | --- |
| C·D의 다른 주행도 학습한 모델 | 0.15 | 0.16 | 0.60 |
| **C·D를 처음 보는 모델** | 0.52 | 0.59 | 0.70 |

- 노면 μ가 0.58~0.65에서 0.43~0.45로 바뀌면 1스텝 오차가 약 3.5배 커진다.

### D3 합성 소형차 (시험용 시험 데이터, 시드 1개)

| | 1스텝 | 1.0초 앞 | μ=0.2 노면 (학습에 없던 값), 1스텝 |
| --- | --- | --- | --- |
| B1 물리 모델 | 0.52 | 2.50 | 1.28 |
| M0 신경망 | **0.47** | **0.39** | **0.85** |

- 신경망이 전부 이긴다. 하지만 물리 모델은 μ가 0.3~1.0으로 다른 주행들을 μ 하나(0.62)로 맞추고 있다. 노면을 모르는 채 공식을 고정해 둔 셈이라 불리하다.

## D2에 대해 새로 알게 된 것

D2는 "뒷바퀴가 미끄러지는 드리프트 데이터"라고 생각했는데, 실제로는 **앞바퀴가 밀리는(언더스티어) 주행이 대부분**이다.

- 운전자가 핸들을 30°로 고정한 채 달리는데, 차는 그 각도로 기대되는 만큼의 절반 정도만 돈다.
- 포화 구간이 84%인데 대부분 앞바퀴 포화다. 뒷바퀴 포화는 23%다.
- 단, D2의 조향 값이 실제 바퀴 각도가 아니라 서보 명령값이면 앞바퀴 미끄러짐이 과대 계산됐을 수 있다. 확인이 필요하다.

## 팀 결정 사항

**정한 것 (11/7)**

1. **노면 μ**: 주 실험은 모델이 μ를 **모르는** 조건으로 한다. 보조 실험으로 μ를 **아는** 조건을 같이 보고해서 "μ를 알면 차이가 얼마나 줄어드는지"를 본다.
2. **주 지표**: **0.5초·1.0초 롤아웃 오차**. 1스텝 오차는 원논문과 비교하는 보조 지표로만 쓴다.

**아직 정할 것**

3. **D1 분할**: 주행이 11개뿐이라 한 번 나눈 결과는 흔들린다. 주행을 돌아가며 빼는 교차검증으로 바꿀지.

## 재현 방법

```bash
python -m models.train --data d1 --model m0 --seed 0     # 신경망
python -m models.train --data d1 --model b1              # 물리 모델
python -m eval.evaluate --data d1 --split test --ckpt "checkpoints/d1/*.pt"
```

데이터 이름: `d1`, `d2`, `d2-tire`(처음 보는 노면), `d3:<합성 데이터 폴더>`. 결과는 `eval/results/`에 저장된다.
