# 물리 모델 검증: CommonRoad와 대조 (11/7)

> 팀원용 요약. 중간 점검 기준 "P1·P2가 CommonRoad와 일치"를 확인한 결과다.

## 결론 먼저

1. **P0, P1은 CommonRoad와 일치한다.** 같은 상태에서 계산한 미분값 차이가 P0는 0.01% 수준, P1은 0.3% 이하다. 남은 차이는 우리 코드가 틀려서가 아니라 CommonRoad 쪽 모델이 조금 더 자세해서 생긴다(아래 설명).
2. **P2의 하중 이동도 맞다.** 선회 중 제동에서 CommonRoad 차가 스핀하는데, 우리 P2도 같은 시점에 스핀한다. 하중 이동이 없는 P1은 스핀하지 않는다.
3. **P2의 결합 슬립(가속·제동하면서 도는 상황)은 근사라서 차이가 있다.** 특히 선회 중 가속에서 이전 방식(마찰 타원)은 차가 도는 방향의 변화를 반대로 예측했다. 대안 방식(피크만 줄임)은 가속에서는 훨씬 잘 맞고, 제동에서는 조금 덜 맞는다. → **P2 기본값을 대안 방식으로 바꿨다** (맨 아래)

## 무엇과 비교했나

[CommonRoad vehicle models](https://pypi.org/project/commonroad-vehicle-models/3.0.2/)는 뮌헨공대에서 만든 표준 차량 모델 모음이다. 그중 두 개를 쓰고, 차는 그 패키지의 BMW 320i 파라미터를 그대로 썼다.

| 우리 모델 | CommonRoad 모델 | 비교 방법 |
| --- | --- | --- |
| P0 (선형 타이어) | ST (선형 단일 트랙) | 같은 상태에서 미분값 비교. ST는 작은 각도로 근사한 식이고 속도를 입력으로 받아서 궤적은 비교하지 않는다 |
| P1 (Pacejka 타이어) | STD (단일 트랙 드리프트) | 미분값 비교 + 조향만 하는 시나리오 3개의 궤적 비교 |
| P2 (P1 + 하중 이동 + 결합 슬립) | STD | 선회 중 제동·가속 시나리오 3개의 궤적 비교 |

STD의 횡방향 타이어 식은 캠버가 0일 때 우리 Pacejka 식과 똑같다. 그래서 계수(μ=1.05, 강성 21.9, C=1.35, E≈0)를 그대로 옮겨 넣었다. 즉 이 비교는 "비슷한 차"가 아니라 **같은 차, 같은 타이어, 같은 입력**이다.

## 결과

### 같은 상태에서 미분값 비교

| 각도 범위 | P0 ~ ST 요레이트 변화율 | P0 ~ ST 슬립각 변화율 | P1 ~ STD 요레이트 변화율 | P1 ~ STD 슬립각 변화율 |
| --- | --- | --- | --- | --- |
| ±0.01 rad | 0.009% | 0.014% | 0.06% | 0.25% |
| ±0.05 rad | 0.19% | 0.31% | 0.03% | 0.06% |
| ±0.1~0.15 rad | 0.9% | 1.1% | 0.03% | 0.02% |

- P0 ~ ST: 각도가 10배 작아지면 차이가 100배 작아진다. ST가 작은 각도 근사(sin x ≈ x)를 쓰기 때문에 생기는 차이이고, 각도가 0으로 가면 두 식이 정확히 같아진다는 뜻이다.
- P1 ~ STD: 0.3% 이하. STD는 바퀴 회전 속도를 따로 계산하고 타이어 식에 작은 보정항이 있어서, 그만큼만 다르다.

### 궤적 비교 (오차 = 최대 오차 / 신호의 최대 크기)

| 시나리오 | 타이어 상태 | 모델 | 요레이트 | 4초 뒤 위치 차이 |
| --- | --- | --- | --- | --- |
| 조향 1° | 선형 | P1 | 0.1% | 0.02 m |
| 조향 10° | 앞바퀴 포화 | P1 | 4.1% | 0.20 m |
| 사인 조향 ±8° | 앞뒤 번갈아 포화 | P1 | 6.4% | 0.43 m (5초) |
| 제동 −3 m/s² | 뒤가 서서히 빠짐 | P2 (마찰 타원) | **1.8%** | 0.37 m |
| | | P2 (피크만 줄임) | 5.8% | 0.34 m |
| | | P1 | 85% | 3.9 m |
| 제동 −6 m/s² | 스핀 | P2 (마찰 타원) | 31% | 1.6 m |
| | | P2 (피크만 줄임) | 32% | 1.6 m |
| 가속 +4 m/s² | 한계 근처 | P2 (마찰 타원) | 18% | 0.77 m |
| | | P2 (피크만 줄임) | **6.0%** | **0.14 m** |
| | | P1 | 41% | 1.9 m |

- 포화 구간에서 오차가 4~6%로 커지는 것은 미분값 차이(0.3% 이하)가 시간이 지나며 쌓인 결과다. 타이어가 포화되면 작은 차이도 크게 벌어진다. 이 성질은 우리 학습 모델의 롤아웃 오차를 해석할 때도 그대로 적용된다.
- 스핀 시나리오의 31%는 스핀이 끝난 뒤 갈라진 값이다. 스핀이 시작되는 시점과 모양은 그림처럼 거의 같다.

## 결합 슬립: 왜 다르고 무엇을 골라야 하나

가속이나 제동을 하면 타이어가 앞뒤 방향으로 마찰을 쓰기 때문에 옆으로 버틸 수 있는 힘이 줄어든다. 이걸 표현하는 방식이 두 가지다.

| 방식 | 하는 일 | 장점 | 단점 |
| --- | --- | --- | --- |
| **마찰 타원** (지금 P2 기본값) | 옆 방향 힘 곡선 전체를 √(1−(Fx/μFz)²)배로 줄인다 | 단순하다 | 미끄러지기 한참 전인 작은 슬립각에서도 옆 힘이 크게 줄어든다(가속 +4 m/s²에서 뒷바퀴 약 30%). CommonRoad는 같은 상황에서 몇 %만 줄인다 |
| **피크만 줄임** (`combined="derate"`, 새로 추가) | 옆 방향 **최대** 마찰만 √(μ²−(Fx/Fz)²)로 줄이고, 작은 슬립각에서의 강성은 그대로 둔다 | Stanford 계열 연구에서 쓰는 방식이다. 가속 시나리오에서 CommonRoad와 3배 더 가깝다 | 이번 제동 시나리오에서는 마찰 타원보다 조금 덜 맞았다 |

CommonRoad 타이어 식(Pacejka 결합 슬립)은 제동과 가속을 다르게 다룬다. 우리 두 방식은 둘 다 대칭이라 어느 쪽도 완전히 같을 수는 없다.

**결정 (11/7): P2 기본값을 "피크만 줄임"으로 바꿨다.**

- 가속 시나리오에서 마찰 타원은 오차가 클 뿐 아니라 요레이트 변화의 방향 자체가 반대였다. 제동에서는 두 방식 모두 스핀 시점을 맞힌다.
- 이전 방식은 `ModelOptions(combined=True)`로 계속 쓸 수 있다.
- D3 시험 데이터를 새 P2로 다시 만들었다: `data/generated/*_v3_trial`. 11/5 기준 모델 문서의 D3 숫자는 이전 방식(`*_v2_trial`)으로 만든 데이터 기준이다.

## 남은 한계

- CommonRoad가 정답은 아니다. 같은 식을 같은 방식으로 구현했는지 확인한 것이고, 실제 차와 맞는지는 D1·D2로 따로 본다.
- 타이어 이완(옆 힘이 바로 생기지 않고 조금 늦게 생기는 현상), 4륜 좌우 하중 이동은 양쪽 모두 없다.
