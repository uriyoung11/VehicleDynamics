## 확인한 것 (11/17)

- **환산이 맞다:** 학습 전 R1(초기값 = Golf 시뮬레이터 추정값)의 D7 시험 1초 롤아웃 RMSE가 vx 0.460 / vy 0.361 / r 0.047로, 우리 Golf 시뮬레이터(0.433 / 0.360 / 0.048)와 거의 같다.
- **경사 효과:** 같은 R1에 경사를 넣으면 vx 오차가 0.460 → 0.386 (약 16% 감소). 시뮬레이터에서 본 효과와 같다.
- 좌우 기울기만(팀원 방식)은 kb 초기값이 0이라 학습 전에는 노면 없음과 같다.
- pedal 모드의 구동·제동 계수(Cm1, Cm2, Cb) 초기값은 대략값이라 학습 전 vx 오차가 크다(1.19 m/s).
- 데이터: D7 학습 28.0분 / 검증 / 시험 5.2분, D1 학습 15.3분 / 시험 2.6분 (25 Hz).

## 비교 결과 ①~⑥ (11/18, R3 1초 손실은 코랩 대기)

D7 시험 주행 3개, 1초 롤아웃. 셀 = vy·r 정규화 오차(시드 3개 평균) / vx 오차 [m/s]. 낮을수록 좋다. 현재값 유지 기준선: 0.619 / 1.94.

| 실험 | R1 | R2 | R4 | R5 | R6 |
|---|---|---|---|---|---|
| ① 기준 (D7, force, 기울기+경사, 1초) | 0.308 / 0.23 | 0.224 / 0.16 | 0.218 / 0.18 | 0.233 / 0.16 | 0.286 / 0.20 |
| ② + D1 | 0.309 / 0.22 | **0.210** / 0.18 | **0.214** / 0.21 | 0.230 / 0.20 | 0.282 / 0.22 |
| ③ pedal | 0.295 / 1.12 | 0.233 / 0.62 | 0.225 / 0.63 | 0.236 / 0.63 | 0.295 / 0.79 |
| ④ 노면 없음 | 0.313 / 0.33 | 0.237 / 0.26 | 0.248 / 0.27 | 0.245 / 0.26 | 0.302 / 0.28 |
| ⑤ 기울기만 (팀원 방식) | 0.311 / 0.32 | 0.234 / 0.25 | 0.231 / 0.27 | 0.237 / 0.24 | 0.293 / 0.27 |
| ⑥ 1스텝 손실 | 0.461 / 0.28 | 0.737 / 0.25 | 0.397 / 0.19 | **0.213 / 0.14** | 0.339 / 0.17 |

- **force > pedal:** pedal은 vx 오차가 3~5배 크다. 횡방향도 R1을 빼면 force가 낫다.
- **기울기+경사(우리 방식) > 기울기만 > 없음:** 모든 모델에서 vx·횡방향 둘 다 낫다. 경사를 빼면 vx 오차가 약 50% 늘어난다.
- **1초 손실 > 1스텝:** R5를 빼고 모두 1초 손실이 낫다. 1스텝 R2·R4·R6은 시드마다 크게 흔들린다(R2 ±0.084).
- **D1 추가는 엇갈린다:** 횡방향은 2~6% 좋아지고 vx는 10~25% 나빠진다.
- **차량 간 평가 (11/19, `cross_eval.py` → `eval/results/ladder_cross.json`):** 같은 ①·②를 D1(GTI) 시험에서도 쟀다 (현재값 유지 0.845 / 1.67).

  | D1 시험 | R1 | R2 | R4 | R5 | R6 |
  |---|---|---|---|---|---|
  | ① D7만 (GTI를 본 적 없음) | 0.396 / 0.58 | 0.377 / 0.70 | 0.339 / 0.66 | 0.469 / 0.76 | 0.450 / 0.68 |
  | ② D7+D1 | 0.324 / 0.52 | 0.261 / 0.19 | **0.225** / 0.50 | 0.277 / 0.16 | 0.335 / 0.20 |

  - 본 적 없는 차(①→D1): 모두 기준선보다 훨씬 낫지만 D7 시험보다 나빠진다. 나빠진 비율은 R1 +29% (물리) < R4 +56% ≈ R6 +57% < R2 +68% < R5 +101% (신경망).
  - 섞으면 D1 시험이 크게 좋아지고(R2 횡 −31%, vx 0.70 → 0.19 m/s), D7 시험은 거의 그대로다. 한 모델로 두 차를 예측할 수 있다.
  - 주의: D1은 다른 코스(본 코스)이고 노면 정보가 없어(0) 차 차이와 코스·노면 차이가 섞여 있다. D7의 Golf도 GTI로 추정돼 두 차가 매우 비슷하다.
- 이긴 쪽을 합친 조합 ⑦ = force + 기울기+경사 + 1초 손실은 D1을 빼면 ①, 넣으면 ②와 같다. 그래서 ⑦을 따로 학습할 필요가 없다.

## 쓰는 법

```python
import sys; sys.path[:0] = ["models/ladder", "."]
import ladder, configs
from train import windows, fit
from data.ladder_data import d7_segments, d1_segments

cfg = configs.golf("force", grade=True)                      # 우리 방식 노면
tr = d7_segments("train", "force", "bank+grade") + d1_segments("train", "bank+grade")   # D7 + D1
va = d7_segments("val", "force", "bank+grade")
model, rec = fit("R2", cfg, windows(tr, cfg.hist, horizon=25), windows(va, cfg.hist, horizon=25), epochs=300)
```
