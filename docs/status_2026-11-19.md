## 2. 지금 쓰는 파일

| 파일 | 역할 |
|---|---|
| [data/thunderhill_west.py](../data/thunderhill_west.py) | 중앙선(OSM + D7 레이싱 라인으로 꺾임 다듬기)과 노면 지도(고도·경사·좌우 기울기). `--split-json`으로 학습 파일만 사용 |
| [data/thunderhill_track_v2.py](../data/thunderhill_track_v2.py) | 트랙 npz 3종(center, mincurv, recorded) + 경계. 실측 폭(`--width-points`) |
| [data/tracks/thunderhill_width_points.csv](../data/tracks/thunderhill_width_points.csv) | 실측 14곳의 트랙 거리 추정값 (팀원 확인 필요) |
| [data/d7_split_team.json](../data/d7_split_team.json) | 팀원 분할 |
| [data/datasets.py](../data/datasets.py), [data/ladder_data.py](../data/ladder_data.py) | D7·D1 로더 (사다리 형식, 경사 채널) |
| [models/ladder/](../models/ladder/) | 사다리 R1~R6 + 경사 채널, 비교 실험(`run_ablation.py`), 차량 간 평가(`cross_eval.py`) |
| [viz/ladder_predict.py](../viz/ladder_predict.py) | 실제 주행을 재생하며 모델의 1초 예측선을 그리는 영상 |

트랙 만드는 명령 (결과는 `data/tracks/v3/`, `v3_local/`, git 제외):

```
python -m data.thunderhill_west --split-json data/d7_split_team.json --out data/tracks/v3/ThunderhillWest_centerline_train.csv
python -m data.thunderhill_track_v2 --center-csv data/tracks/v3/ThunderhillWest_centerline_train.csv --split-json data/d7_split_team.json --out data/tracks/v3
python -m data.thunderhill_track_v2 --center-csv data/tracks/v3/ThunderhillWest_centerline_train.csv --split-json data/d7_split_team.json --width-points data/tracks/thunderhill_width_points.csv --out data/tracks/v3_local
```

## 3. 트랙 v3 오차

| 항목 | 크기 | 근거 |
|---|---|---|
| 경사 | RMS 0.09°, 95%가 0.2° 안 (가속도 0.016 m/s²) | 지도에 쓰지 않은 시험 주행 3개의 GPS 상하 속도와 비교 |
| 기록선(recorded) | 최대 0.013 m | 기록 랩과 비교 |
| 폭, 측정 지점 | ±0.2 m | 3회 측정 평균 |
| 폭, 측정 없는 600~2,350 m | ±0.5~0.8 m (추정) | 평균 10.9 m 사용 |
| 경계 좌우 위치 | 보통 코너 ±1 m, 헤어핀(1,853 m, 2,401 m) 안쪽 최대 +2 m | 코너 정점에서 D7 바퀴와 안쪽 경계 사이 간격 (중앙값 1.15 m, 최소 −0.03 m) |
| D7 주행이 경계 안에 드는가 | 전부 (균일 폭) / 3 m 구간에서 1 cm 걸침 (위치별 폭) | 20개 주행 |

A 방식(기록선 추종)에서는 오차가 작다. B 방식(경계 안 최대 전진)에서는 헤어핀 안쪽 경계가 가장 큰 불확실성이다.

## 4. 남은 일

| 항목 | 내용 |
|---|---|
| 사다리 결과 다시 내기 | 11/19 이전 결과(①~⑥, 차량 간 평가, 레이스)는 **이전 우리 분할**이다. 팀원 분할로 다시 학습·평가해야 팀원 결과와 같은 표에 놓을 수 있다 |
