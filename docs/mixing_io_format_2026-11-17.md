# 여러 차 데이터 혼합 학습과 입출력 형식 비교 (11/17, 진행 중)

두 가지를 차례로 시험한다.
1. **혼합 학습:** 다른 차(GTI, Golf)의 데이터를 섞어 학습해도 되는가, 어떻게 섞는 게 나은가
2. **입출력 형식:** 이력 길이, 시간 간격, Ux 예측 여부, 종방향 입력(힘/페달) 중 무엇이 나은가

결과는 학습이 끝나는 대로 이 문서에 채운다.

## 1. 왜 하나

- 풀스케일 한계 실데이터는 D1(GTI, 20분)과 D7(Golf, 39분)뿐이다. 둘 다 Thunderhill에서 같은 연구실(Stanford)이 모았다.
- 차가 다르면 같은 입력에도 반응이 다르다. 그냥 섞으면 두 차의 평균을 배울 수 있다. 섞는 방법에 따라 이득과 손해가 갈리는지 실험으로 확인한다.
- 이 실험은 "물리 구조가 일반화를 돕는가"라는 주 질문과도 이어진다. 물리 구조 모델(B1, M1~M3)이 차를 넘어 지식을 더 잘 공유하는지 볼 수 있다.
- 입출력 형식은 우리(Spielberg 형식)와 팀원 IAC 코드(Deep Dynamics 형식)가 다르다. 어느 쪽이 나은지 같은 데이터에서 비교한다.

## 2. D7 데이터 준비

| 항목 | 내용 |
|---|---|
| 출처 | [purl.stanford.edu/hh613qz0317](https://purl.stanford.edu/hh613qz0317), CC BY-SA 4.0. 연결 논문: Mori et al., "Physics informed neural network vehicle model for highly dynamic automated driving" |
| 파일 | 22개(395 MB). `2023-10`과 `10_2`, `10_1`과 `10_3`이 바이트 단위로 같아(md5) 20개 사용. 로컬 `data/d7/` |
| 처리 | 200 Hz → 100 Hz(두 샘플 평균), Ux > 2 m/s 연속 구간 |
| 분할 (파일 단위) | 학습 14개 28.6분, 검증 3개 4.9분, 시험 3개 5.2분 (10월·11월 섞음) |
| 구간 비율 | 정상 69%, 비선형 29%, 포화 2% (D1은 83 / 16 / 1) |
| 부호 규약 | D1과 같음. 조향 대비 요 레이트 기울기 1.50 (D1 1.48). 두 차는 거동이 매우 비슷하다 |
| 차량 제원 | 공개 자료에 없음. GTI 프리셋(`fullscale`)으로 대신한다. 질량은 브레이크 힘과 감속도 관계로 약 1630 kg 추정 |

**종방향 입력 만들기.** D1의 `fxf`는 앞바퀴 축 종방향 힘이다. 가속할 때는 전체 힘과 같고(기울기 0.96), 제동할 때는 전체의 66%다(기울기 1.49 ≈ 1/0.66). D7에서 같은 뜻의 값을 세 가지로 만들었다.

| 이름 | 만드는 법 | 쓰는 곳 |
|---|---|---|
| `d7` (기본) | 전체 힘/m = dUx/dt − Uy·r. 앞바퀴 몫은 가속 1(전륜구동), 제동은 앞 브레이크 힘/전체 브레이크 힘 | [r, Uy]만 예측할 때. 측정 가속도라 Ux를 예측하면 정답이 새어 들어간다 |
| `d7a` | 엔진 토크 × 기어비 − 앞 브레이크 힘. 계수는 최소제곱으로 보정 (가속도 설명력 R² 0.937) | Ux까지 예측할 때 (미래 정보 없음) |
| `d7p` | 스로틀/100, 제동 중이면 −브레이크 압력/최대 (팀원·Deep Dynamics 형식) | 힘 vs 페달 비교. 페달만으로는 가속도 설명력 R² 0.507 |

모델 입력은 힘/(m·100)이라 질량이 약분된다. Golf 질량을 몰라도 D1과 단위가 맞는다. 범위도 비슷하다(1~99분위 D1 −6.9~6.5 kN, D7 −6.4~7.4 kN).

## 3. 1단계: 혼합 학습

| 학습 데이터 | 이름 | 설명 |
|---|---|---|
| GTI만 | `d1` | 기준 |
| Golf만 | `d7` | 기준 |
| 그냥 섞기 | `d1+d7` | 차 정보 없이 합침 |
| 차 구분 채널 추가 | `d1+d7\|veh` | 입력 6번째 채널에 차 번호(GTI 0, Golf 1). 신경망 부분만 이 채널을 쓴다 |

- 모델: B1, M0, M1, M2, M3 (B1은 신경망이 없어 차 구분 채널을 쓰지 않으므로 마지막 줄은 빼고 19개)
- 시드 0, 1 → 학습 38개. 체크포인트는 `checkpoints/mix/<학습 데이터>/`
- 평가: 모든 모델을 GTI 시험과 Golf 시험 둘 다에서 평가한다(차 구분 모델은 채널을 붙인 시험 데이터로). `python -m eval.mix_eval` → `eval/results/mixing.json`
- "물리 구조로 섞기(차마다 제원은 따로, 신경망은 공유)"는 Golf 제원이 없어 이번에는 하지 않았다.

**결과 (11/17, `eval/results/mixing.json`)**

Golf 시험(D7) 1초 롤아웃 nRMSE, 시드 0 / 1. 현재값 유지 기준선은 0.62 (GTI 시험 0.85).

| 학습 데이터 | B1 | M0 | M1 | M2 | M3 |
|---|---|---|---|---|---|
| GTI만 | 0.49 / 0.50 | 0.53 / 0.54 | 22.0 / 29.1 (발산) | 1.52 / 2.48 | 1.02 / 0.50 |
| Golf만 | 0.42 / 0.42 | 1.12 / 4.90 | 0.33 / 0.42 | 0.59 / 0.67 | 1.52 / 3.33 |
| **그냥 섞기** | 0.42 / 0.43 | 0.31 / 2.44 | **0.32 / 0.32** | 2.40 / 1.59 | 0.30 / 0.27 |
| 차 구분 채널 | – | 0.46 / 0.40 | 0.33 / 0.41 | 1.21 / 0.61 | 0.52 / 0.84 |

GTI 시험(D1)에서는 그냥 섞은 M1이 0.27 / 0.26으로 가장 좋다(GTI만 학습한 M1은 0.62 / 0.32).

1. **GTI를 섞으면 Golf 예측이 좋아지고 안정된다.** M1: Golf만 0.33 / 0.42 → 섞기 0.32 / 0.32.
2. **GTI로만 학습해 Golf에 쓰면 위험하다.** M1 발산, M2·M3 크게 나빠짐. 물리가 단순한 B1·M0는 버텼다. 차가 바뀌면 신경망 부분이 엉뚱하게 외삽한다.
3. **차 구분 채널은 도움이 안 됐다.** 두 차가 비슷해(조향 대비 회전 1.50 vs 1.48) 구분할 이득이 없었던 것으로 본다.
4. **모델 안정성:** M1이 가장 안정적이다. M3는 섞기에서 수치가 가장 좋지만 다른 조합에서 자주 발산한다. M0는 시드에 따라 0.31 / 2.44로 갈린다. M2는 대부분 현재값 유지보다 나쁘다.
5. 원단위: 섞은 M1의 Golf 1초 오차 r 0.034 rad/s, Uy 0.36 m/s (현재값 유지 0.152, 0.474).

→ 2단계는 **그냥 섞기(GTI + Golf)**, 모델 B1·M0·M1로 한다. 시드 편차가 커서 롤아웃 손실로 다시 학습하는 것이 여전히 필요하다.

## 4. 2단계: 입출력 형식 비교 (1단계 뒤)

1단계에서 고른 데이터 조합으로 한다. 형식 말고 다른 조건(데이터, 모델, 학습 방법, 지표)은 고정한다.

| 형식 | 간격 | 이력 | 출력 | 종방향 입력 |
|---|---|---|---|---|
| F1 지금 (Spielberg) | 0.01 s | 4스텝 = 0.04 s | [r, Uy] | 힘 |
| F2 이력 늘림 | 0.01 s | 20스텝 = 0.2 s | [r, Uy] | 힘 |
| F3 | 0.02 s | 10스텝 = 0.2 s | [r, Uy] | 힘 |
| F4 | 0.04 s | 5스텝 = 0.2 s | [r, Uy] | 힘 |
| F5 Ux 예측 | 0.02 s | 0.2 s | [r, Uy, Ux] | 힘 (`d7a`) |
| F6 Ux 예측 (팀원과 같은 간격) | 0.04 s | 0.2 s | [r, Uy, Ux] | 힘 (`d7a`) |
| F7 페달 (Golf만) | 0.02 s | 0.2 s | [r, Uy, Ux] | 페달 (`d7p`) vs 힘 (`d7a`) |

- 모델: B1, M0, M1 (Ux 출력을 지원하는 모델. 팀원의 R1, R5, R2와 같은 계열). 시드 2개
- 뱅크(노면 경사)는 Thunderhill이 평지에 가까워 이번 비교에서 뺀다. 팀원 실험(LVMS)에서는 필수였다.
- 학습 방법(코사인 학습률, 기울기 자르기)은 팀원과 다르지만 근거가 약한 항목이라, 한 조합에서만 따로 비교한다.

## 5. 이번에 바꾼 코드

| 파일 | 바뀐 점 |
|---|---|
| `data/datasets.py` | `load_d7`(accel / actuator / pedal), 이름 조합 `"d1+d7"`, 차 구분 채널 `"\|veh"`, 간격 늘리기 `"@k"`(예: `d1@2` = 0.02 s), `windows(..., n_out)` |
| `models/baselines.py`, `models/hybrid.py` | 입력 채널 수를 표준화 통계에서 정함(차 구분 채널 대응). M0, B1, M1에 `n_out=3`(Ux 예측) |
| `models/train.py` | `--n-out`, 폴더 이름의 `\|`를 `_`로 |
| `eval/metrics.py` | 롤아웃 시간을 초 단위로 환산(간격이 달라도 "1초"가 같은 1초), Ux 오차, **원단위 RMSE**(rad/s, m/s), **현재값 유지 기준선**(`Hold`). 기존 결과는 그대로 재현됨(M0·B1 D1 시험 값 소수 넷째 자리까지 같음) |
| `eval/mix_eval.py` | 혼합 실험 평가 (새 파일) |

`mean`은 출력 형식이 달라도 비교되도록 항상 r, Uy 두 채널 평균이다.

참고로 현재값 유지 기준선은 D1 시험 1초 롤아웃에서 무차원 0.850(r 0.295 rad/s, Uy 0.364 m/s)이고, 기존 M0은 0.370(0.046 rad/s, 0.249 m/s)이다.

## 6. 팀원 IAC 코드와의 차이 (요약)

| 항목 | 우리 | 팀원 |
|---|---|---|
| 데이터 | GTI + Golf, 한계 근처 | AV-21, 최대 0.57 g |
| 입출력 | 0.04 s 이력 → [r, Uy], 힘 | 0.32 s 이력 → [vx, vy, r], 페달, 뱅크 |
| 학습 | 검증 최저 상태 저장, M1 2단계 학습 | 300에폭 마지막 저장, 코사인, R2 한 번에 학습(물리·잔차 상쇄 −0.99) |
| 지표 | 무차원 + (이번에 추가) 원단위, 구간별 | 원단위, 현재값 유지·직선 외삽·선형 기준선 |

2단계의 F5~F7이 팀원 형식을 우리 데이터에서 시험하는 부분이다.

## 7. 다시 돌리는 방법

```
python -m models.train --data "d1+d7" --model m0 --seed 0 --out checkpoints/mix/d1+d7/m0_s0.pt
python -m models.train --data "d1+d7|veh" --model m1 --seed 0 --out checkpoints/mix/d1+d7_veh/m1_s0.pt
python -m eval.mix_eval
python -m models.train --data "d1+d7a@2" --model m0 --T 10 --n-out 3     # 2단계 예: 0.02 s, 0.2 s 이력, Ux 예측
```

D7 데이터는 저장소 메타데이터(`https://purl.stanford.edu/hh613qz0317.xml`)의 파일 목록을 `https://stacks.stanford.edu/file/druid:hh613qz0317/<경로>`에서 받아 `data/d7/`에 둔다.
