# M1~M3 설계 (11/12)

코드: [models/hybrid.py](../models/hybrid.py). 학습·평가는 M0·B1과 같은 [models/train.py](../models/train.py), [eval/evaluate.py](../eval/evaluate.py)를 쓴다.

## 공통 규칙

- **입출력:** 다섯 모델(M0~M3, B1)이 모두 같다.
  - 입력: 과거 4스텝 × [r, Uy, Ux, δ, 종방향 입력]
  - 출력: 0.01초 뒤 [r, Uy]
  - Ux는 예측하지 않는다(원논문과 같음).
- **파라미터 예산:** 신경망 파라미터 수를 1% 안으로 맞췄다.

  | 모델 | 파라미터 수 |
  |---|---|
  | M0 | 19,458 |
  | M1 | 19,461 |
  | M2 | 19,334 |
  | M3 | 19,461 |

- **μ를 주지 않는다** (11/7 결정, 주 실험). 노면 상태는 모델이 과거 이력에서 알아내야 한다.
- **물리 부분은 B1과 같은 P1 모델**(Fiala 타이어, 하중 이동·결합 슬립 없음)이다.
  - 학습 대상: 앞뒤 코너링 강성 배율과 μ 배율.
  - 합성 데이터를 만든 P2보다 단순한 물리를 일부러 썼다. 같은 식으로 만들고 같은 식으로 맞추면 비교가 무의미해지기 때문이다(project.md 3-1).
- **D2(모터 전류) 지원:** "구동력 = k × 전류"의 k를 같이 학습한다. 초기값은 m·dUx/dt ≈ k·I의 최소제곱으로 정한다. 그래서 B1과 달리 M1·M2·M3는 D2에서도 돈다.
- **학습률:** 물리 파라미터는 신경망보다 10배 큰 학습률을 쓴다. 물리가 먼저 맞춰지고 신경망이 나머지를 배우게 하려는 것이다.

## 물리의 양 순서

M0(없음) < M3(손실에만) < M2(동역학 식) < M1(동역학 + 타이어 식) < B1(전부, 신경망 없음)

## M1 물리 잔차

**구조:** 상태 미분 = P1 물리 미분 + 신경망 잔차

- 잔차 신경망은 마지막 층을 0으로 시작한다. 그래서 학습 초기 예측은 B1과 정확히 같다(검증: 차이 0.0).
- 신경망은 "물리가 설명하지 못하는 부분"만 배운다. 하중 이동, 결합 슬립, 센서 잡음이 여기에 해당한다.

**근거**
- [Kabzan et al. 2019, Learning-based MPC for autonomous racing](https://arxiv.org/abs/1901.08184): 공칭 모델 + 미분 잔차 학습. 이 논문은 잔차를 가우시안 프로세스(GP)로 배운다.
- [Węgrzynowski et al. 2024](https://arxiv.org/abs/2408.15610) (D2 논문)의 PCR: Pacejka 자전거 모델 + 잔차 MLP.
- Spielberg 박사논문.

## M2 신경망 타이어

**구조:** 운동 방정식(질량, 관성, 축 위치)은 고정하고, 앞뒤 타이어 횡력만 신경망이 낸다.

```
Fy = -μ̂ · Fz · tanh( c·α + g(α, Fx/Fz, Ux) − g(−α, Fx/Fz, Ux) )
```

| 설계 | 보장하는 성질 | 근거 |
|---|---|---|
| g(α) − g(−α) | α에 대해 홀함수. 슬립이 0이면 힘이 0이고 좌우가 대칭이다 | 타이어 기본 성질 ([Neural-ExpTanh, Djeumou et al. 2023](https://arxiv.org/abs/2306.06330)) |
| tanh × μ̂·Fz | \|Fy\| ≤ μ̂·Fz. 마찰 한계를 넘는 힘이 나올 수 없다 | ExpTanh 논문은 벌점으로 했고, 여기서는 구조로 강제했다 |
| 앞의 −부호와 c·α | 미끄러지는 반대 방향으로 힘이 난다. 학습 시작점은 "공칭 코너링 강성을 가진 포화 타이어"다 | 부호 규약은 ExpTanh 논문과 같다 |
| μ̂ = 과거 이력으로 추정한 마찰 | 힘이 노면 μ에 비례해 줄어든다 | D2 논문 NNTF (아래) |
| 입력에 Fx/Fz | 종방향 힘을 쓰면 횡력이 줄어드는 효과(결합 슬립)를 배울 수 있다 | |

**μ로 스케일한 이유:** D2 논문에서 학습 때 못 본 타이어(μ 33% 낮음)로 시험했을 때의 결과다.
- 스케일 없는 신경망 타이어(NNT)는 **불안정해졌다.**
- **μ로 스케일한 신경망 타이어(NNTF)가 가장 좋았다.**
- 순수 신경망(NN)은 크게 나빠졌다.

D2 논문은 μ를 칼만 필터(UKF) 상태로 추정했다. 우리는 MPC와 UKF 없이 예측만 하므로, 과거 4스텝 이력을 보는 작은 신경망이 μ̂을 낸다.

**추가로 참고한 것:** [Kim et al. 2022 (Deep Pacejka Model)](https://arxiv.org/abs/2207.07920)는 Pacejka 식을 신경망 안에 층으로 넣었다. 우리는 Pacejka 모양을 강제하지 않고 성질만 강제한다.

## M3 물리 손실 (PINN)

**구조:** M0와 같다. 추론할 때는 신경망만 쓴다. 학습할 때만 손실에 물리 벌점을 더한다.

```
손실 = 데이터 1스텝 오차 + λ_c · 제약 벌점 + λ_m · P1 잔차 벌점
```

1. **제약 벌점** (λ_c = 1.0)
   - 예측한 미분(ṙ, U̇y)을 운동 방정식으로 거꾸로 풀어 앞뒤 타이어가 냈어야 할 횡력을 구한다. 식이 2개, 미지수가 2개라 바로 풀린다.
   - 그 힘이 마찰 한계 μ_max·Fz를 넘으면 벌점을 준다. μ를 모르므로 μ_max = 1.2로 넉넉하게 잡았다.
   - 그 힘이 미끄러지는 방향과 같은 쪽이면 벌점을 준다. 슬립각 1.1° 이하는 잡음 때문에 제외한다.
   - 타이어 모양을 가정하지 않는다. 물리 법칙(뉴턴 법칙, 마찰 한계, 힘의 방향)만 쓴다.
2. **P1 잔차 벌점** (λ_m = 0.1): 예측 미분이 P1 물리 미분에서 너무 멀어지지 않게 한다. P1의 강성과 μ는 같이 학습한다.
3. **collocation:** 위 벌점을 학습 데이터에도 주고, 데이터 상태(r, Uy, δ)를 표준편차의 0.5배만큼 흔든 **라벨 없는 점**에도 준다. 데이터가 없는 영역에서도 물리를 지키게 하는 PINN의 핵심 장치다.

**근거**
- PINN의 기본 틀(손실 속 물리, collocation): Raissi, Perdikaris, Karniadakis 2019 (J. Comput. Phys.).
- 차량 단일 트랙 모델을 손실에 넣은 예: [arXiv 2303.00474](https://arxiv.org/abs/2303.00474).
- [Chalmers 석사논문 2025](https://odr.chalmers.se/items/c165b646-f005-495d-9d2d-2ca901885276).
- 마찰 한계 벌점과 부호 규약: Neural-ExpTanh.

## 검증한 것

[tests/test_physics.py](../tests/test_physics.py)와 별개로, 구현 직후 확인한 내용이다.

- M1~M3가 D3·D1·D2 데이터에서 출력 모양, 유한값, 기울기 전달이 모두 정상이다.
- M1의 초기 예측이 B1과 정확히 같다.
- M2 타이어는 무작위 가중치에서도 슬립 0 → 힘 0, 홀함수, |g| ≤ 1이 성립한다.
- 체크포인트를 저장했다가 불러와도 예측이 같다.

### 읽은 것

1. **M3(물리 손실)가 가장 고르게 좋다.**
   - D3에서 1초 오차가 가장 낮다.
   - 처음 보는 μ(범위 안)에서 M0보다 약 2.8배 낫다(0.83 vs 2.31).
   - 추론 구조는 M0와 같으므로, 학습 때 준 물리 벌점(collocation 포함)만으로 일반화가 좋아졌다. RQ3을 지지하는 첫 근거다.
2. **물리 구조가 있는 모델은 긴 롤아웃에서 M0보다 안정적인 경우가 많다(RQ1).**
   - D2 1초: M0 3.56(발산 수준), M1 0.72, M2·M3 약 1.36.
   - D3 처음 보는 μ에서 M2·M3가 M0보다 낫다.
3. **M1은 1스텝은 좋은데 D3 롤아웃이 발산한다(1초 8~15).** 문제가 두 가지다.
   - D3: 잔차 신경망이 물리 미분에 더해지면서, 자기 예측을 다시 넣는 롤아웃에서 오차가 증폭된다.
   - D1: 물리 부분이 사실상 꺼졌다. 학습된 μ가 0.05, 강성 배율이 0.8과 2.1이 되어 신경망이 전부 떠맡았다.
   - 반면 D2에서는 M1이 가장 좋다. 고칠 방향은 아래 "남은 일"에 적었다.
4. **M2(신경망 타이어)는 중간이고, D1에서 약하다(1스텝 0.45 vs M0 0.05).** 풀스케일 차량에서 타이어 신경망 입력 크기, μ̂ 초기값, 학습률이 맞는지 확인이 필요하다.
5. **D1에서는 B1(물리만)이 가장 좋다.**
   - 1스텝 검증 오차는 가장 나빴는데(1.87), 0.5초·1초 롤아웃은 가장 좋다.
   - 1스텝 순위와 롤아웃 순위가 다르다. 11/7에 롤아웃을 주 지표로 정한 이유가 그대로 드러난다.
6. **처음 보는 μ(범위 밖)에서는 M0가 가장 좋다.** 물리 구조가 항상 일반화에 유리하지는 않다. 시드 5개로 확인해야 한다.

**주의:** 모두 시드 1개 결과다. 결론은 시드 5개 재학습 후에 낸다.

학습 실행 명령(데이터마다 세 모델을 동시에 돌린다. 이 PC 기준 전체 약 1시간):

```
for data in d3:data/generated/f1tenth_v3_trial d1 d2; do
  tag=$(python -c "from models.train import data_tag; print(data_tag('$data'))")
  for m in m1 m2 m3; do
    python -m models.train --data $data --model $m --seed 0 --threads 4 > logs/${tag}_${m}_s0.log 2>&1 &
  done
  wait
done
```

평가 명령:

```
for sp in test test_mu_interp test_mu_extrap; do
  python -m eval.evaluate --data d3:data/generated/f1tenth_v3_trial --split $sp --ckpt "checkpoints/f1tenth_v3_trial/*.pt"
done
python -m eval.evaluate --data d1 --split test --ckpt "checkpoints/d1/*_s0.pt"
python -m eval.evaluate --data d2 --split test --ckpt "checkpoints/d2/*_s0.pt"
```

## 남은 일

- **M1 안정화**: 잔차 크기에 벌점(L2)을 주거나, B1으로 물리 파라미터를 먼저 맞춘 뒤 고정하고 잔차만 학습(2단계). 물리 파라미터 범위 제한(Deep Dynamics의 Physics Guard처럼)
- **M2 풀스케일 점검**: D1에서 타이어 신경망 입력 정규화, μ̂ 초기값, 학습률
- 시드 5개 재학습(다른 모델과 함께)
- μ를 주는 보조 실험: M1·M2의 μ 자리에 실제 μ를 넣는 옵션
- M3 벌점 가중치(λ_c, λ_m), collocation 크기 민감도
- 롤아웃 손실(여러 스텝을 이어서 학습): 주 지표가 롤아웃이라 모든 모델에 같이 적용하는 것을 검토
